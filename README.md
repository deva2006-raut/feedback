# 💬 Feedback System

A simple **feedback collection platform** with an admin dashboard — collect feedback from users and manage it all in one place. Built with vanilla JavaScript, no frameworks required.

## ✨ Features

- 📝 **Feedback collection** — public feedback form
- 🙏 **Thank-you page** — smooth post-submission experience
- 🔐 **Admin login** — protected management area
- 📊 **Admin dashboard** — view and manage submitted feedback
- ⚙️ **Automation page** — workflow automation tools
- 💾 **Local persistence** — feedback stored in the browser via `localStorage`

## 🛠️ Tech Stack

| Layer      | Technology                    |
| ---------- | ----------------------------- |
| Frontend   | HTML, CSS, Vanilla JavaScript |
| Storage    | localStorage (browser)        |
| Build step | None ✅                       |

## 🚀 Getting Started

No installation needed:

```bash
git clone https://github.com/deva2006-raut/feedback.git
cd feedback
```

Then open **`index.html`** in your browser — or serve it locally:

```bash
npx serve .
# or
python -m http.server 8080
```

## 📁 Pages

```
├── index.html       # Landing page
├── feedback.html    # Feedback form

├── admin.html       # Admin login & dashboard
└── automation.html  # Automation tools
```
